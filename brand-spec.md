# Parallax Brand Specification

- Product: Parallax, an engineering operations agent.
- Audience: engineering leads, project managers, and teams coordinating work across GitHub, Jira, Slack, and Notion.
- Visual direction: Light Control Room.
- Primary character: operational, calm, precise, dense, and trustworthy.
- Palette: graphite navigation, warm-neutral working canvas, blue-green action accent, and semantic status colors.
- Typography: Geist Sans for interface content and Geist Mono for technical metadata.
- Imagery: none in the application dashboard; product state and evidence carry the visual identity.
- Brand mark: compact Parallax monogram treatment; no copied third-party artwork.
